# Шёлковый путь — сайт-путеводитель по Узбекистану

Одностраничный сайт о маршруте Самарканд · Бухара · Хива · Ташкент. Учебный проект.

**Сайт онлайн:** https://muhammadyus.github.io/silk-road-site/

## Стек

| | |
|---|---|
| Разметка | HTML5 |
| Стили | чистый CSS (без фреймворков), шрифты Google Fonts |
| Логика | ванильный JavaScript, без зависимостей и сборки |

## Как запустить

```bash
cd ~/projects/silk-road-site
python3 -m http.server 8080
```

Открыть http://localhost:8080. Можно и просто открыть `index.html` двойным кликом.

## Структура

```
silk-road-site/
├── index.html   # разметка всех секций
```
