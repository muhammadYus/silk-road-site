# Шёлковый путь — сайт-путеводитель по Узбекистану

Многостраничный сайт о маршруте Самарканд · Бухара · Хива · Ташкент. Учебный проект.

**Сайт онлайн:** https://muhammadyus.github.io/silk-road-site/

## Стек

| | |
|---|---|
| Разметка | HTML5, 11 страниц |
| Стили | чистый CSS: тёмная и светлая темы, анимации, адаптив |
| Логика | ванильный JavaScript без зависимостей и сборки |
| Карта | встраиваемая Google Карта (iframe, без API-ключа) |
| Фото | 27 снимков с Wikimedia Commons под свободными лицензиями |
| Хостинг | GitHub Pages |

## Как запустить локально

```bash
cd ~/projects/silk-road-site
python3 -m http.server 8080
```

Открыть http://localhost:8080.

## Страницы

| Страница | Что умеет |
|---|---|
| `index.html` | Звёздное небо на canvas, карусель мест, счётчики, хронология, сезоны |
| `samarkand.html`, `bukhara.html`, `khiva.html`, `tashkent.html` | Места с фото, карта города, советы (аккордеон), галерея |
| `tours.html` | 4 маршрута: фильтры по длительности и городу, сортировка, программа по дням |
| `map.html` | Google Карта: список мест, поиск, фильтр по городам, расстояния, маршрут в Google Картах |
| `gallery.html` | Фильтр по городам, просмотр фото (стрелки, свайп, Esc), таблица авторов и лицензий |
| `planner.html` | Города, дни и порядок, бюджет, избранное, ссылка на план, печать |
| `contacts.html` | Форма с проверкой полей, «Мои заявки», FAQ |
| `404.html` | Страница «не найдено» для GitHub Pages |

## Структура

```
silk-road-site/
├── *.html        # страницы (у городов и разделов — тонкие оболочки)
├── styles.css    # дизайн, темы, анимации, мобильная версия
├── script.js     # шапка/подвал, избранное, лайтбокс, логика страниц
├── data.js       # города, места с координатами, туры, FAQ
├── photos.js     # фото: подпись, автор, лицензия, ссылка на оригинал
└── img/          # фото, сжатые до 1280 px
```
